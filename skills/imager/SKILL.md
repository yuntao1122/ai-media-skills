# Imager · AI 图片工作流

## 什么时候用

用户要"画一张 XX""做个封面/海报/配图""生成插画"时。核心不是"按一次生成"，而是"拆解 → 生成 → 评审 → 迭代"的闭环。

## 输入

- 用途：文章配图 / 视频封面 / 海报 / 插画（决定比例和风格）
- 主体描述（一句话：画面里必须有什么）
- 风格偏好（写实/扁平/赛博/水墨/电影感……不确定就问一句）
- 比例：16:9 / 1:1 / 9:16 / 3:2（按用途默认：视频封面 16:9，手机壁纸/短视频 9:16）
- 文字需求：**默认不在图里放文字**——AI 生图最容易翻车的就是文字；必须放时用后期叠加

## 工作流

### 1. 拆画面要素

动笔前先把六要素定死，缺哪个问用户一句：

| 要素 | 示例 |
|---|---|
| 主体 | 一只橘猫 |
| 场景 | 蹲在书堆上 |
| 风格 | 电影感、浅景深 |
| 构图 | 特写、三分法 |
| 光线 | 午后侧光、暖调 |
| 色调 | 暖黄、胶片质感 |

### 2. 写 prompt

模板（中英混写即可，关键风格词用英文更稳）：

```
<主体>, <场景>, <构图>, <光线>, <色调>, <风格关键词>, <质量词>
```

质量词：`high detail, sharp focus, professional photography`（写实）/ `flat design, vector style`（扁平）。**反向要求**单独写：`no text, no watermark, no deformed hands`。

### 3. 生成与评审

生成后按检查清单评审，不要凭感觉"好像还行"：

- [ ] 主体对不对（数量、特征、动作）
- [ ] 有没有穿帮：手、文字、logo、透视
- [ ] 风格统一吗（和用户要的一致吗）
- [ ] 构图留白够吗（封面要留标题位置）

### 4. 迭代

**一次只改一个变量**：主体不对改主体描述，风格不对改风格词。不要整句重写——否则不知道哪改对了。一般 2–3 轮收敛，超过 5 轮还没对，说明第一步要素没拆清，回去重拆。

### 5. 定稿与适配

定稿后说明：原图比例、可裁剪方向（16:9 改 1:1 从中间裁是否成立）、是否需要去水印/放大。

## 风格关键词速查

| 中文 | 英文关键词 |
|---|---|
| 电影感 | cinematic, film still, dramatic lighting |
| 扁平插画 | flat illustration, minimal, vector style |
| 赛博朋克 | cyberpunk, neon lights, futuristic |
| 水墨国风 | chinese ink painting, traditional |
| 产品摄影 | product photography, studio lighting, clean background |
| 绘本风 | storybook illustration, soft colors |

## 注意事项

- 人物特写先看手和脸，远景先看整体氛围——评审要有优先级。
- 商用前确认生成工具的版权条款，logo/商标不要直接生成。
- 同一套图的多张画面，风格词保持一致，否则就是两套图。
