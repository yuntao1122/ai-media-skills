# Director · AI 视频工作流

## 什么时候用

用户说"做个视频""把这期内容剪成短视频""写个分镜"时。默认做**短视频**（1–3 分钟）；长视频先问一句。

## 输入

- 主题（一句话）
- 时长：默认 60–90 秒
- 平台：抖音/视频号（9:16）/ B站（16:9）/ 小红书（3:4）——决定比例和节奏
- 素材：已有文案/素材（可来自 hunter+curator），或从零开始
- 配音：AI 配音 / 真人 / 纯字幕+音乐

## 工作流

### 1. 定结构（先写骨架，再填肉）

短视频三段式，按 90 秒分配：

| 段 | 时长 | 干什么 |
|---|---|---|
| 钩子 | 0–5 秒 | 一句话留人：反常识、提问、结果前置。写 3 个备选 |
| 正文 | 5–75 秒 | 3 个点，每个点 1 个论据，多一个都砍 |
| 结尾 | 75–90 秒 | 总结 + 行动号召（关注/评论/收藏三选一，别全要） |

### 2. 写分镜脚本

用分镜表，每镜一行：

| 镜号 | 时长 | 画面 | 文案/配音 | 音效/音乐 |
|---|---|---|---|---|
| 1 | 0–5s | <画面描述> | <配音文案> | <音效> |

文案按口语写：短句、每句一个意思，90 秒约 220–260 字。画面描述要具体到 imager 能直接画的程度。

### 3. 准备视觉素材

- 静态图：调 `imager` 按分镜批量生成，**风格词全片统一**。
- 动态片段：图生视频时 prompt 只描述"运镜+动作"（如"缓慢推镜，云层流动"），不要重复描述画面内容；文生视频先出关键帧确认再批量。
- 现成素材：注明来源，可商用的才用。

### 4. 组装剪辑

顺序：粗剪（按分镜表拼）→ 配音对齐 → 字幕 → 音乐（音量压到人声的 20–30%）→ 封面（用 imager 做 16:9/9:16 各一版，标题字后期叠）。

### 5. 成片检查清单

- [ ] 前 3 秒有没有钩子（静音刷到也能看懂吗）
- [ ] 字幕错别字（逐字过一遍，AI 配音尤其注意多音字）
- [ ] 音乐版权（商用授权/平台曲库）
- [ ] 画面风格统一，无穿帮帧
- [ ] 结尾行动号召只有一个
- [ ] 导出参数：平台推荐分辨率和码率

## 和其它 skill 的串联

```
hunter（搜集选题素材）→ curator（筛出 3 个论据）→ director（写分镜）
                                                     → imager（按分镜做图）
                                                     → 成片
```

## 注意事项

- 分镜表是导演和所有后续步骤的合同：分镜不定，不要开生成，返工成本最高。
- AI 视频片段目前适合做空镜、转场、氛围镜头；有人物特写和复杂动作时，优先用静态图+运镜代替。
- 文案先定稿再配音，配音定了再卡剪辑——倒着返工最贵。
